# مستندات فنی و قرارداد اتصال به درگاه پرداخت زرین‌پال (MEYVAN Payment API Spec)

این سند مشخصات فنی دو Endpoint سرورلس مورد نیاز برای پردازش امن تراکنش‌های مالی فروشگاه طلا و جواهر میوان را تشریح می‌کند.

---

## اصول امنیتی
1. **عدم ذخیره کلید محرمانه (Merchant ID / Secret) در فرانت‌اند**: فرانت‌اند یک برنامه استاتیک روی GitHub Pages است و تحت هیچ شرایطی نباید به کلید زرین‌پال دسترسی داشته باشد.
2. **محاسبه مجدد قیمت سمت سرور**: کلاینت تنها لیست اقلام (`sku` و `quantity`) را به همراه مشخصات مشتری ارسال می‌کند. سرور موظف است وزن کالا را از کاتالوگ استخراج نموده، با آخرین نرخ لحظه‌ای طلای ۱۸ عیار ضرب کرده و مبلغ نهایی را محاسبه و به درگاه زرین‌پال ارسال کند تا از دستکاری قیمت توسط کاربر جلوگیری شود.
3. **قفل زمانی نرخ طلا**: پس از ایجاد تراکنش، قیمت حداکثر به مدت ۱۰ دقیقه معتبر است.

---

## ۱. ایجاد سفارش و دریافت لینک درگاه: `/create-order`

- **متد:** `POST`
- **آدرس:** `${VITE_PAYMENT_API}/create-order`
- **هدرها:** `Content-Type: application/json`

### بدنه درخواست (Request Body)
```json
{
  "items": [
    {
      "sku": "MY-0042",
      "quantity": 1
    },
    {
      "sku": "MY-0120",
      "quantity": 2
    }
  ],
  "customer": {
    "fullName": "سارا محمدی",
    "mobile": "09123456789",
    "province": "یزد",
    "city": "یزد",
    "address": "خیابان کاشانی، کوچه مریم، پلاک ۱۲",
    "postalCode": "8916712345",
    "shippingMethod": "express_post",
    "notes": "لطفاً هدیه بسته‌بندی شود"
  },
  "createdAt": "2026-10-11T10:45:00.000Z"
}
```

### وظایف سرور:
1. اعتبارسنجی مقادیر ورودی و شماره موبایل.
2. فراخوانی کاتالوگ طلا و دریافت وزن و اجرت هر `sku`.
3. ضرب در آخرین نرخ ۱۸ عیار و محاسبه مبلغ نهایی (به تومان / ریال).
4. درخواست توکن از زرین‌پال (`https://api.zarinpal.com/pg/v4/payment/request.json`) با تنظیم `callback_url` به سمت `https://meyvan.ir/#/payment-result`.
5. بازگرداندن `paymentUrl` به کلاینت.

### پاسخ موفق سرور (Response 200 OK)
```json
{
  "success": true,
  "orderId": "ORD-948215",
  "authority": "A00000000000000000000000000287463921",
  "paymentUrl": "https://www.zarinpal.com/pg/StartPay/A00000000000000000000000000287463921"
}
```

## ۲. تایید و وریفای تراکنش: `/verify`

- **متد:** `POST`
- **آدرس:** `${VITE_PAYMENT_API}/verify`
- **هدرها:** `Content-Type: application/json`

### بدنه درخواست (Request Body)
```json
{
  "authority": "A00000000000000000000000000287463921",
  "orderId": "ORD-948215"
}
```

### وظایف سرور:
1. دریافت `authority` و ارسال درخواست به متد `payment/verify.json` زرین‌پال با ارسال `merchant_id` و مبلغ ذخیره‌شده‌ی همان سفارش.
2. بررسی کد پاسخ زرین‌پال (کد ۱۰۰ یا ۱۰۱ نشان‌دهنده موفقیت تراکنش است).
3. ثبت کد رهگیری بانکی (`ref_id`) در دیتابیس یا فایل لاگ سفارشات.
4. ارسال پیامک تایید خرید به مشتری با شماره پیگیری.

### پاسخ موفق سرور (Response 200 OK)
```json
{
  "success": true,
  "refId": "12847192",
  "orderId": "ORD-948215",
  "message": "پرداخت با موفقیت تایید شد."
}
```

### پاسخ خطای سرور (Response 400 Bad Request)
```json
{
  "success": false,
  "code": -51,
  "message": "تراکنش ناموفق است یا توسط کاربر لغو شده است."
}
```
