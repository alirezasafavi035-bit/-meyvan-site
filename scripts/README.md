# راهنمای موتور استخراج و مهاجرت محصولات از Dorreh Gold به میوان (MEYVAN)

این اسکریپت پایتون، داده‌های کلیه محصولات را از وب‌سایت **Dorreh Gold (dorrehgold.ir)** استخراج، تمیزسازی، نرمال‌سازی و تبدیل کرده و **بدون هیچ‌گونه حذف یا جایگزینی (Non-destructive Appending)** به کاتالوگ محصولات فروشگاه آنلاین **MEYVAN (meyvan.ir)** اضافه می‌کند.

## ۲. ساختار و فیلدهای تبدیل داده (Schema Mapping)

تمام اقلام استخراج‌شده بر اساس استاندارد محاسبه طلا و ساختار اختصاصی میوان نرمال‌سازی می‌شوند:

| فیلد میوان | نوع داده | نحوه استخراج از دره‌گلد | مقدار پیش‌فرض / فال‌بک |
| :--- | :--- | :--- | :--- |
| `sku` | رشته یکتا | تولید شناسه پایدار هش‌شده (`MY-DOR-XXXXX`) | الزامی و یکتا |
| `name` | رشته | عنوان اصلی قطعه در تگ `h1.product_title` | متن بدون کاراکترهای زائد |
| `category` | کلید دسته‌بندی | تشخیص هوشمند بر اساس عنوان و بردکرامب (`ring`, `earrings`, ...) | `necklace` |
| `weightGrams` | اعشاری (گرم) | استخراج با الگوی رگولار از مشخصات یا توضیحات محصول | ۲.۵۰ گرم |
| `karat` | عدد صحیح | استاندارد طلای ۱۸ عیار ایران (۷۵۰) | ۱۸ |
| `wagePercent` | اعشاری | استخراج درصد اجرت ساخت از فیلد کارمزد | ۰.۱۶ (۱۶٪ مصوب صنف) |
| `profitPercent` | اعشاری | سود مصوب اتحادیه طلا و جواهر | ۰.۰۷ (۷٪) |
| `vatPercent` | اعشاری | مالیات بر ارزش افزوده طلا (۱۰٪ صرفاً روی اجرت+سود) | ۰.۱۰ (۱۰٪) |
| `images` | آرایه رشته | گالری تصاویر با بالاترین رزولوشن اصلی | آرایه لینک‌های مستقیم |
| `sourceUrl` | رشته | نشانی یکتای صفحه محصول در dorrehgold.ir | شناسه اعتبارسنجی عدم تکرار |

## ۳. شیوه‌های اجرای مهاجرت

### راهکار الف (Solution A): ارسال از طریق API اختصاصی میوان
در صورتی که وب‌سایت مقصد اندپوینت مدیریت محصولات تحت API داشته باشد:

```bash
python scripts/migrate_dorrehgold.py \
  --mode api \
  --api-url "https://meyvan.ir/api/products" \
  --api-token "YOUR_BEARER_AUTH_TOKEN_HERE" \
  --delay 1.5
```

### راهکار ب (Solution B): افزودن مستقیم به فایل کاتالوگ و خروجی اکسل/CSV
اگر وب‌سایت به صورت SPA عمل کرده و از مخزن فایل استاتیک `public/data/products.json` استفاده می‌کند:

```bash
python scripts/migrate_dorrehgold.py \
  --mode all \
  --catalog-file "public/data/products.json" \
  --output-csv "dorreh_migrated_products.csv" \
  --delay 1.2
```

## ۴. سازوکار حفظ محصولات فعلی و جلوگیری از تکرار (Zero-Overwrite Policy)

1. **نسخه پشتیبان خودکار (Automatic Backup):** پیش از افزودن هر محصول، یک نسخه بک‌آپ با پسوند `.backup-<timestamp>` از فایل کاتالوگ ایجاد می‌شود.
2. **بررسی عدم تکرار (Deduplication):** اسکریپت آدرس `sourceUrl` و شناسه `sku` را با ۵۱۶ محصول فعلی میوان تطبیق می‌دهد؛ در صورت وجود رکورد مشابه، از افزودن مجدد صرف‌نظر شده و محصول ثبت‌شده حفظ می‌شود.
3. **افزودن الحاقی (Append-Only):** رکوردهای جدید در انتهای آرایه افزوده می‌شوند و رکوردهای موجود دست‌نخورده باقی می‌مانند.

## ۶. رعایت قوانین اخلاقی و فنی وب (Ethical Scraping Compliance)

- **رعایت محدودیت نرخ (Rate Limiting):** پارامتر `--delay` با مکث ۱.۲ الی ۲ ثانیه از بار اضافی بر سرور مبدأ جلوگیری می‌کند.
- **تلاش مجدد خودکار (Exponential Backoff):** پاسخ‌های خطای ۴۲۹ یا ۵xx سرور با فواصل افزایشی بازنشانی می‌شوند.
- **پایش و لاگ زنده:** تمام مراحل در فایل `dorreh_migration.log` ثبت می‌شوند.
